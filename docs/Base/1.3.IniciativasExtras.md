# 1.3. Iniciativas Extras (DAS & Reutilização)

A entrega mínima pedia o DAS com a Visão Lógica, mais uma visão e uma evidência de algo rodando. As iniciativas abaixo vão além desse mínimo e seguem o formato usado nas [Iniciativas Extras da Entrega 02](https://unbarqdsw2026-2-turma02.github.io/2026.2-T02-_G6_ProjetoAplicativoMovel_Entrega02/#/Base/1.3.IniciativasExtras).
